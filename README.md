# Fortuna

Static landing page for Fortuna Laboratories.

Open `index.html` directly, or serve the directory with any static file server.
There are no packages, build steps, or runtime dependencies.

## Structure

- `index.html` — content and document structure
- `styles.css` — layout, responsive design, and animation
- `script.js` — small progressive enhancements
- `assets/` — Fortuna artwork and social preview
- `worker.js` — minimal static hosting adapter
